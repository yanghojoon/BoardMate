# U7 / Step 07 · 표현 조정과 접근성

**목표:** Step 02~06에서 구현한 실제 RealityKit 도구의 재질·조명·가독성을 함께 검수하고 접근성을 완성한다. 도구를 다시 제작하거나 임시 모델을 최종 모델로 전면 교체하는 단계가 아니다.
**요구사항:** DIC-03, TIM-04, TOK-01·03, PRD 06·07절.
**선행:** U4·U5·U6.

## 작업

- [ ] 기존 월넛 책상·아이보리 주사위·황동 모래시계·저광택 동전의 표현을 통합 점검하고 필요한 재질 값·텍스처만 조정한다.
- [ ] 기존 따뜻한 조명·부드러운 그림자·비스듬한 상단 시점을 도구별 조작 패널과 함께 맞춘다.
- [ ] 투명 유리가 모래·시간·동전 숫자를 가리지 않게 재질을 조정한다.
- [ ] 주사위 10개 결과와 토큰 각 단위 숫자의 읽힘을 실제 화면에서 확인한다.
- [ ] 숫자·시간·수량은 SwiftUI에도 제공하고 단위 구분에 색상만 사용하지 않는다.
- [ ] 선택·실행·입력·리셋에 VoiceOver 이름과 상태 설명을 제공한다.
- [ ] Dynamic Type·작은 화면·키보드 표시 상태에서 조작 영역을 검증한다.
- [ ] 동작 줄이기 사용 시 카메라·굴림 효과를 줄이면서 최종 상태를 유지한다.
- [ ] 자산 실패 시 예외 경로인 대체 도형과 안내를 검증한다. 기존 자산 목록의 출처·제작 방식·허용 범위를 확인하고 추가 자산이 있으면 갱신한다.

## 접근 방식

PRD 제안 색은 월넛 #38291F, 아이보리 #EEE3CD, 황동 #967443, 모래 #C8AF82, 크림 #F5F0E6이다. 실제 조명 아래의 가독성을 기준으로 조정하며 이 HTML을 최종 앱 화면의 시각 기준으로 취급하지 않는다. 이 단계에서 도메인 규칙이나 기능 범위를 바꾸지 않는다.

## 검증 시나리오

1. 동일한 주사위 결과를 재질·조명 조정 전후 표시 → 윗면과 숫자가 동일하고 엔티티 축·눈금 매핑이 유지된다.
2. 모래 진행률 0·50·100% → 상하 모래와 남은 시간이 읽힌다.
3. VoiceOver로 세 도구와 실행·리셋·추가·제거를 조작 → 이름·값·비활성 상태를 알 수 있다.
4. 동작 줄이기로 주사위 굴림·카메라 전환 → 과도한 움직임 없이 동일 결과에 도달한다.
5. 큰 글자·키보드·작은 화면 → 주요 실행 버튼과 오류 안내에 접근할 수 있다.
6. 모델 로딩 실패 → 대체 도형과 일반 UI가 표시되고 데이터는 유지된다.

**완료 기준:** `Docs/QA/Visual-Accessibility.md`에 책상·도구별 화면과 검수 조건을 기록한다. 기능 회귀 테스트가 통과하고 실제 기기에서 수치·단위·시간 판독이 가능하다. 최종 프레임·메모리 통과 판정은 Step 08에서 수행한다.
