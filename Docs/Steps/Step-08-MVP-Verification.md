## 추가 경계·성능

- [ ] 전환·굴림 도중 앱 이탈 → 복귀 시 카메라·결과·입력 잠금이 정상이다.
- [ ] 리셋과 이전 회차 종료 이벤트 충돌 → 이전 이벤트가 새 상태를 변경하지 않는다.
- [ ] 토큰 여러 입력 중 하나만 잘못됨 → 유효 항목도 부분 반영되지 않는다.
- [ ] 최악 조건: 주사위 10개·전 단위 최대 토큰·모래시계 진행·투명 유리·그림자를 동시에 표시한다.
- [ ] 기기 모델·OS·빌드 구성·측정 시간·평균 및 저하 구간 프레임·메모리 추이를 기록한다.
- [ ] 도구 전환 반복 후 엔티티·이벤트 구독·타이머가 누적되지 않고 메모리가 안정되는지 확인한다.
- [ ] Xcode Debug·Release 빌드, Swift 컴파일 진단, Analyze와 테스트를 확인한다. 별도 린터가 없는 경우 새 의존성을 추가하지 않는다.
- [ ] 기능 결함은 최소 재현 회귀 테스트를 추가한 뒤 수정하고 영향을 받은 검수만 다시 실행한다.

## 증거와 완료 판정

테스트 결과에는 실행일, 기기·OS, 설정값, 기대/실제 결과, 스크린샷·영상 또는 테스트 결과 경로를 기록한다. 자동 검증과 실기기 관찰을 구분한다. 시뮬레이터의 시간·수량 성공으로 실제 진동·흔들기·렌더링 성능을 통과 처리하지 않는다.

**완료 기준:** A-01~12 모두 통과, 확정한 성능 기준 충족, 필수 동작을 막는 알려진 결함 0개, 미정 정책의 결정 기록 완료. 하드웨어 미확보 항목은 미검증으로 표시한다. 완료 보고에 변경 파일·검증 결과·남은 제한을 포함한다. App Store 배포는 이 단계에 자동으로 포함하지 않는다.
