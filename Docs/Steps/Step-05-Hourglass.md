# U5 / Step 05 · 모래시계와 시간 생명주기

**목표:** 화면 밖에서도 시간이 흐르고, 종료·리셋·복귀를 정확하게 처리한다.
**요구사항:** TIM-01~06, A-02·03·04·06·11·12.
**선행:** U2·U3. P-04 시간 입력, P-05 비활성 만료 진동 정책을 확정한다.

## 작업

- [ ] 기본 3분·시작 대기와 시간 설정·시작·리셋 UI를 구현한다. 일시정지는 추가하지 않는다.
- [ ] 시작 때 종료 기준 시각을 저장하고 남은 시간을 0 이상으로 계산한다.
- [ ] 도구 선택과 관계없이 루트 세션에서 만료를 감지한다.
- [ ] 앱 이탈 중 갱신이 없어도 활성 복귀 시 실제 경과를 반영한다.
- [ ] 리셋 시 이전 회차를 무효화하고 설정 시간·모래 양·대기 상태를 복원한다.
- [ ] 활성 앱 종료는 다른 도구 사용 중에도 회차당 한 번 진동을 전달한다.
- [ ] 진동 전달 여부를 세션 회차에 기록하고 화면 복귀·중복 갱신으로 재전달하지 않는다.
- [ ] 위·아래 모래 부피와 낙하 효과를 시간 진행률에 연결한다.
- [ ] Step 02의 황동·유리 모래시계와 모래 엔티티를 재사용한다. 대기·실행·종료·리셋에 따라 낙하 효과를 켜고 끄며, 복귀 시 현재 진행률로 즉시 맞춘다.
- [ ] 비활성 중 만료·복귀 진동은 P-05를 따르며, 백그라운드 전달을 보장한 것으로 표기하지 않는다.

## 접근 방식

남은 시간의 원본은 종료 기준 시각과 현재 시각의 차이다. 화면 갱신 횟수·모래 애니메이션·초당 감소 카운터를 실제 시간으로 사용하지 않는다. 진동은 가시 패널의 소유가 아니며, 루트에서 완료된 회차를 한 번 소비하는 방식으로 구성한다. 모래알별 물리 대신 진행률에 따른 형상·효과를 사용한다.

## 테스트 시나리오

1. 60초 시작 후 주입 시계를 20초 이동하고 도구 왕복 → 약 40초다.
2. 앱 비활성 20초 후 동일 세션 복귀 → 약 40초, 60초 이상 후 복귀 → 0·종료다.
3. 다른 도구에서 활성 상태로 만료 → 종료 진동 호출 1회, 모래시계 복귀 → 추가 호출 없음.
4. 실행 중·종료 후 리셋 → 설정 시간·대기·초기 모래 양. 시작 전 감소 없음.
5. 리셋→새 시작 후 이전 회차 지연 콜백 → 새 회차의 값·진동을 변경하지 않는다.
6. 만료 갱신·도구 복귀·활성 전환 중복 → 음수 없음, 중복 진동 없음.
7. 0·음수·빈 값·P-04 상한 초과 → 설정되지 않는다. 시작 연타 → 한 회차다.
8. 실제 iPhone에서 새 회차를 다시 시작해 만료 → 새 회차에도 한 번 진동한다.

**완료 기준:** 시계 기반 단위 테스트, UI 왕복·복귀 검증, 실제 iPhone의 활성 종료 진동 확인. 모래 진행률은 0·중간·100%에서 위·아래 양과 남은 시간이 일치한다.
