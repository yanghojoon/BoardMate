# Step 02 자산 목록

2026-10-27. 모든 형상과 재질은 앱 내부에서 RealityKit 기본 메시와 시스템 글꼴로 생성한다. 외부 모델·텍스처·네트워크 다운로드·별도 라이선스가 필요한 자산은 사용하지 않는다. 모델 로딩이나 대체 도형 경로는 없다.

| 자산 | 제작 경로 | 피벗·단위·구성 | 출처·권한 |
| --- | --- | --- | --- |
| 아이보리 D6 | `DiceEntityFactory` | 미터, 변 0.10. 루트는 책상 바닥, `die-body` 중심은 y=0.05. 둥근 모서리·여섯 면의 검은 눈금 | 프로젝트 자체 제작, RealityKit 생성 메시 |
| 모래시계 | `HourglassEntityFactory` | 높이 0.30, 반경 0.086. 루트는 바닥 중앙. 황동 상하판·기둥, 분리된 상하 유리·모래·낙하 기둥 | 프로젝트 자체 제작, RealityKit 생성 메시 |
| 표본 토큰·받침 | `TokenEntityFactory` | 받침 0.25×0.19, 동전 지름 0.068·두께 0.008. 1·5·10·20·50 양각. 루트는 받침 바닥 중앙 | 프로젝트 자체 제작, 시스템 볼드 글꼴의 메시 |
| 재질 | `EntityMaterials` | 저광택 아이보리·검은 눈금·황동·모래·녹색 펠트·월넛. 유리는 투명도 0.16 PBR | 프로젝트 자체 색상·RealityKit 재질 |

D6 로컬 축은 1=+Y, 2=+Z, 3=+X, 4=−X, 5=−Z, 6=−Y다. 마주 보는 눈의 합은 7이다. `orientation(showing:)`는 해당 면의 법선을 +Y로 보내는 최종 회전이며, 실제 굴림 기능에서 `die-body`에 적용한다. 루트의 책상 위치와 선택 충돌 영역은 장면이 소유한다.

모래 진행률은 실제 시간과 분리된 시각 표현이다. 0·0.5·1 주입을 지원하고 범위를 벗어난 입력은 제한한다. 모래 체적에 비례하도록 길이 스케일에 세제곱근을 적용한다. 개별 모래알 물리는 구현하지 않는다. 유리와 모래의 겹침·가독성은 실제 iPhone에서 추가 검수한다.

받침의 다섯 동전은 제작·단위 식별용 표본이며 사용자의 보유량이 아니다. 초기 보유량 0은 화면에 별도로 표시하며, 표본이나 향후 동전의 유무에 관계없이 받침의 선택 영역을 유지한다. Step 03~06에서 세션 모델과 실제 지급·회수·타이머·굴림 기능을 연결한다.
